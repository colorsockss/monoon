# LedgeRun 검수 결과

2026-11-26 macOS 27.0.1 arm64, 기준 커밋 `8f7e622`, 작업 브랜치 `remake/ledgerun`.

## 7차 키캡과 타이틀 정렬

키캡은 22px 높이의 둥근 사각형이다. 고운돋움의 SDL_ttf 글자 폭에 굵게 표시할 여유를 더해 각 레이블의 기본 폭을 잡았다. 칩은 레이블 좌우에 최소 2px씩 두고, 글자 배율 200%에서는 폭과 여백이 함께 늘어난다. 외곽 반경은 4px이며 9-slice를 써서 폭이 달라져도 모서리가 유지된다. 타이틀, 일시정지, 구간 결과와 정상 결산에 같은 키캡을 쓴다.

타이틀의 하단 바는 각 키캡과 동사 사이 4px, 다섯 묶음 사이 5px을 두고 내용의 폭에 맞춘다. 출발을 누르면 `Depart` 글자색이 바뀐다. 구간 설명 카드에서는 제목과 기록을 같은 왼쪽 선에 맞추고, 두 줄을 카드의 세로 가운데에 놓았다. 결산은 키캡 두 개와 동사를 5px씩 띄워 버튼 가운데에 배치한다.

| --- | --- |
| 1 | 2배 오버레이에서 키캡 좌우 여백과 하단 바의 단일 테두리를 확인했다. 200%의 글자 상자가 키캡 높이보다 1px 컸고, 구간 설명은 두 줄 간격이 넓었다. 칩 높이를 22px로 올리고 설명의 두 줄을 가운데로 모았다. |
| 2 | 1280×720에서 100%·200% 타이틀과 일시정지, 결산을 확인했다. 2배 오버레이에서 글자 상자가 칩 안에 들어오고, 결산의 두 칩과 동사가 한 줄 가운데에 놓이는 것을 확인했다. |

## 5차 우편 모자와 Trailhead

Courier의 모든 자세와 타이틀 삽화에 납작한 정수리·짧은 챙·봉투 휘장이 있는 청록 천 모자를 넣었다. 결산 도장의 가운데에도 같은 모자를 그렸다. 산길과 봉투는 작은 PNG로 그리고, 고운돋움 글자에 어두운 외곽선과 아래 그림자를 겹쳤다. 타이틀의 기본 배율에서는 워드마크를 키웠고, 200%에서는 삽화와 글자가 겹치지 않도록 별도 크기를 사용한다. [Courier 4배 시트](courier-animation-4x.png)

슬롯마다 도달한 구간까지 네 아이콘이 차례로 켜진다. 빈 슬롯은 `NEW`, 진행 중인 슬롯은 보석 수와 아직 등록되지 않은 원정 시간을 나타내는 `--`을 표시한다. 시간은 한 원정에서 네 구간을 모두 마쳤을 때만 갱신한다. 이전 저장의 개별 구간 최단 기록은 선택한 구간의 `Leg best`에 표시한다. 슬롯의 보석 수는 세 수집 구간의 보석 최고 기록 합이다. 기존 저장 형식에 최단 원정 틱 값을 추가해 이전 슬롯도 읽는다.

버튼·알약의 글자 높이는 UI의 줄 높이 계산에 맡겨 글자 배율을 따라가게 했다. 슬롯에는 일정한 높이의 제목 행과 아이콘 행, 통계 행을 두고, 결산과 타이틀에서는 그림자가 붙은 패널 안쪽을 기준으로 글자의 높이를 맞췄다. [글자 크기 200%](text-scale.png)

## 4차 Courier와 아케이드 UI

큰 노란 챙 모자, 산호색 스카프, 봉인한 편지가 든 가방으로 산길 우편배달부의 실루엣을 만들었다. 프레임을 26×28px에서 36×40px로 키웠고, 새 대기 자세의 불투명 영역은 31×38px이다. 새 스프라이트의 발 위치를 기존 바닥 접점에 맞추고 캡슐 폭과 높이는 14×20으로 유지했다. 가방, 챙, 스카프가 좁은 탑이나 한쪽 발판에 걸리지 않도록 한 선택이다. 같은 입력으로 네 구간을 완주하고 클리어 틱·토큰·보석·슬롯 저장을 대조했다. [Courier 세 시안](courier-concepts.png)

대기 6프레임과 달리기 8프레임을 포함해 12개 상태를 한 팔레트로 그렸다. 착지와 점프 준비에 몸을 낮추고, 벽에서 손을 내밀 때 먼지를 낸다. 대시에는 따뜻한 잔상을 쓰고, 승리 자세에서는 봉인 편지를 들어 올린다. 승리와 밟기 자세를 Warden과 같은 장면에서 확대해 확인했다. [스테이지별 Courier 4배 확대](courier-4x.png) · [애니메이션 시트 4배 확대](courier-animation-4x.png)

밝은 알약 HUD는 하트·토큰·보석의 숫자가 바뀔 때 튄다. 제목 배너는 위에서 내려와 튀고, 결산은 `DELIVERED` 배지가 찍힌 뒤 시간·토큰·보석을 차례로 센다. 정상 HUD에는 Warden 얼굴과 3칸 체력 바를 넣었다. Trailhead의 세 슬롯 카드 중 현재 슬롯의 노란 판이 커진다. F3의 모션 줄이기는 UI 트윈을 줄이고 결산을 즉시 표시한다.

저장소의 고운돋움 TTF와 라이선스를 쓴다. 라틴 문자와 숫자 위주의 UI에서 기존 부분 글꼴로 충분하다. 200%에서 빠지는 기호는 ASCII 표기로 바꿨다. 글꼴 크기 선택은 화면에 `1x` 또는 `2x`로 표시한다. 새 글꼴 후보나 런타임 의존성은 추가하지 않았다.

## 엔진 보강 후보와 미확인 항목

- 창 없는 새 배포에서 내장 셰이더를 굽는 경로가 `No accelerated offscreen shader surface is available.`로 중단됐다. 이번 하네스와 크기 검사는 레시피 입력과 SHA-256이 일치하는 캐시 시트를 재사용했다. 내장 시트를 장치 독립적으로 사전 생성하거나 체크아웃 간에 공유하는 방법이 후보다.
- 결산 열은 고운돋움 숫자의 폭을 사용한다. 글꼴과 배율에 따라 오른쪽에 맞추는 기능을 공통 UI 텍스트에 넣으면 샘플의 숫자 폭 표를 없앨 수 있다.
- 이전 Scene Play 실행은 `HIServices._RegisterApplication → NSApplication.sharedApplication → InitializeAvnApp`에서 `SIGABRT`로 종료했다. 화면 서비스 없이 Scene Play의 캡처를 비교하는 경로가 후보다. [이전 Scene Play 로그](../../../.artifacts/ledgerun-scene-play/LedgeRun.Play/run.log)
- 초회 플레이 시간, 실제 창·GPU, Windows·Linux는 이번 검수 범위 밖이다. VM과 SSH는 사용하지 않았다. [Linux 기록](linux-x64-route.txt)과 [이전 검수 해시](macos-arm64-review-sha256.tsv)는 이전 버전의 기록이다.
- 변경은 코디네이터 인계를 위해 `remake/ledgerun` 워크트리에 남겼다.
