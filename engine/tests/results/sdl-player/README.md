# KeyRoom의 SDL3 배포 플레이어 검증

2026-11-17, macOS 27.0.1 arm64. 변경 전 배포본을 보관하고 같은 KeyRoom 프로젝트를 Distribution 프로필로 다시 빌드했다. Release와 Native AOT의 실제 SDL 창을 각각 실행했다.

| 빌드 | 변경 전 앱 (바이트) | 변경 후 앱 (바이트) | 변경 전 ZIP (바이트) | 변경 후 ZIP (바이트) |
| --- | ---: | ---: | ---: | ---: |
| Release | 102,236,838 | 94,947,966 | 38,982,077 | 35,840,967 |
| Native AOT | 22,860,984 | 15,880,297 | 9,270,208 | 6,240,347 |

앱 용량은 일반 파일의 길이와 심볼릭 링크 자체 길이의 합계다. 두 ZIP은 `ditto -c -k --keepParent`로 만들었다. 새 ZIP의 CRC, 실행 권한, SDL의 상대 심볼릭 링크를 검사했다. 패키지 파일 목록과 동적 로딩 로그에서 SDL3를 확인했고 SkiaSharp는 발견되지 않았다. Release의 `.deps.json`도 확인했다.

- 원본 게임에서 I로 가방을 열고 L로 한국어로 전환했다. OCR로 가방·휴대용 나침반·황동 열쇠 문구를 읽었다. 폰트 로그에서 ‘가·방’은 Gowun Dodum, ‘휴·황’은 Nanum Gothic을 선택했다. [가방 패널 캡처](korean-inventory.png)
- 마스크 검사는 임시 KeyRoom 복사본의 참나무에 가로 세 칸짜리 알파 마스크(255, 128, 0)를 지정했다. 두 모드 모두 마스크 적용 전후의 차이를 확인했다. 원본 프로젝트와 용량을 잰 앱에는 이 마스크를 추가하지 않았다. [참나무 캡처. 왼쪽은 원본, 오른쪽은 마스크 적용](oak-mask.png)

비교 영역은 창 제목 표시줄을 제외한 1600 × 900 게임 화면 기준이다. 변경 전 Release·Native AOT와 변경 후 Release·Native AOT 네 캡처에서 다음 RGB 바이트가 모두 일치했다.

| 영역 | x, y | 너비 × 높이 | 다른 픽셀 | RGB SHA-256 |
| --- | --- | --- | ---: | --- |
| 가방 패널 | 480, 300 | 640 × 300 | 0 | `e7ec5150549fd61891dd758d4e5a342bdecb8f878fd3cc0d1594d372dda71889` |
| 마스크 적용 참나무 | 486, 344 | 204 × 196 | 0 | `f1252e8715472bb21dca64437972a5a8fb72c0ffc18b7288a64f54e5fac1bf00` |

Windows 11과 Debian 12의 x64 배포 폴더·ZIP 용량과 같은 영역에서 캡처한 화면은 [Windows·Linux x64 검증 기록](x64/README.md)에 있다.
