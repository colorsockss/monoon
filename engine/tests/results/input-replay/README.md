저장소 루트에서 `./monoon test replay game-builds/InventoryLab`으로 같은 파일을 다시 검사할 수 있다. `./monoon ci`에서도 앱과 심볼을 새로 빌드한 후 기존 스모크 검사와 이 재생 검사를 모두 수행했다. Release 빌드 ID는 `f904b373c5fc48578ab1c8798f7c2fc3`, Native AOT는 `2deb557d3c504618bf02967d5fcec6f1`이었다. [로컬 CI 로그](ci.txt) · [사용법](../../../../docs/manual/build.md#헤드리스-입력-리플레이)
