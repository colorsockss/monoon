## 7차 검수

- 같은 4,570틱을 계측한 결과, 전투 중의 `SetActive` 호출이 장면 전체의 부모·자식 조회를 다시 만들었다. 6차에서 UI 노드가 늘면서 이 조회의 비용도 커졌다. 검 궤적은 기존 클립이 끝나면 빈 스프라이트로 돌아가도록 두고, 룬·크라운·월드 체력 바는 기존 렌더러의 불투명도로 표시한다. 화살은 비활성화 시 트레일이 지워지는 기존 경로를 사용한다.
- Pulse 충전 링은 단계가 바뀔 때 영향을 받는 두 조각의 너비만 갱신한다. 크라운과 레벨에 공용 숫자 문자열을 쓰고, 장비·Pulse 안내의 고정 문자열을 캐시했다. HUD 값이 같으면 기존 텍스트와 배치를 재사용한다.
- 글자 200%에서 Pulse와 남은 시간 또는 준비 상태를 한 줄에 둔다. 폭은 6초 이하 표기 116px, 준비 표기 146px이다. 크라운·레벨 패널은 1–2자리일 때 116→96px로 줄이고, 3–4자리에는 필요한 폭을 남긴다. 패널 오른쪽 가장자리와 XP 바의 여백을 유지했다.

### 화면과 정렬

- 크라운과 레벨 배지를 한 줄에 두고 XP 바는 패널 너비에 맞춰 아래에 놓았다. 크라운 수와 XP가 오르면 짧은 트윈으로 반응한다. 방패 초상의 간격은 22px이고, 동일한 5px 높이의 금빛 체력 바 아래로 피해를 붉은 밀랍색으로 표시한다. 쓰러진 초상에는 X가 뜬다.
- Wave 점과 적 문장을 한 줄에 고정했다. 웨이브·상호작용 패널과 Pulse의 공통 높이는 36px이다. Pulse의 12단계 충전 링이 가득 차면 짧게 빛난다. 글자 200%에서는 Pulse 이름과 상태를 두 줄로 쌓아 링과 한 패널에 유지한다. 알림이나 보스 체력 바가 필요한 순간에는 웨이브 띠를 접어 전투 HUD가 최대 **19,428 / 129,600 논리 픽셀(14.99%)**을 차지한다.
- 보스의 이름·상태·체력을 두 줄로 배치했다. 관문 알림과 상점에는 키캡을 넣고 상점 가격은 같은 열에 놓았다. 오른쪽 페이지의 문구·버튼·서명은 같은 왼쪽 선을 공유한다. 기록 레이블과 값은 두 열에 같은 행 간격으로 배치했다. 장부의 동작은 클릭 또는 키보드로 선택할 수 있으며, 버튼 선택과 누름은 테두리와 가죽 명암으로 구분된다.
- 1280×720의 기본 글자에서 보조 레이블 `Lv` 픽셀 높이는 15px다. 가죽과 종이 안쪽의 글자색 대비는 검수한 배색에서 최소 **6.12:1**이다. UI는 색인 PNG와 SDL3의 9-slice를 쓰고, 글자는 기존 GowunDodum TTF를 SDL_ttf로 렌더링한다. 런타임 의존성 추가는 0개다.

## 5차 검수

- Wave·Foes, Pulse, 크라운·레벨, 퀘스트 띠의 글자를 논리 8.5px로 키웠다. 1280×720 기본 글자 크기의 실제 글리프 높이는 검수 표본에서 15–21px였다. 가죽 본문 영역의 가장 밝은 배경 위에서 양피지색 본문의 대비는 최소 **10.04:1**이다. 크라운과 Pulse 메달은 글자 중심에 맞추고, 큰 글자에서는 Pulse 이름과 상태를 두 줄로 표시한다. 패널 배치를 조정해 전투 HUD 최대 면적을 **19,434 / 129,600 논리 픽셀(14.995%)**로 제한했다.
- 흰 덩어리는 피격 애니메이션에서 인물 전체를 불투명한 밝은 색으로 덮은 첫 프레임이 원인이었다. 피부·의상·적의 원래 명암 위에 재질 색을 약하게 섞었다. 처치 시에는 작은 반투명 퍼프를 여러 겹으로 띄운다. 습지는 갈색, 망령은 보라색, 돌과 Stag는 회색 계열의 시트와 수명 곡선을 공유한다. 같은 Pulse 첫 프레임의 전투 영역에서 밝은 불투명 실루엣과 같은 색 범위에 든 가장 큰 연결 성분은 2,424px에서 12px로 줄었다.
- 데미지 표기는 36틱(0.6초) 동안 오르며 진한 외곽선을 유지한다. 같은 대상의 숫자는 옆자리부터 찾고, 화면이 붐비면 겹치지 않는 위치가 있을 때 표시한다. 기본 크기에서 치명타와 Pulse만 1.32배로 키웠다. 숫자와 외곽선은 SDL_ttf 월드 텍스트 12묶음으로 재사용한다.
- 장부 왼쪽에 습지 9·유적 12·묘지 7마리, 최종 레벨 8·인원 4명·전투 지역 시간 0:58을 표시하는 것을 확인했다. 시간은 필드 입장부터 각 지역 완료까지의 시뮬레이션 틱을 누적하며, 메뉴와 전환 시간 및 Haven 체류 시간은 뺀다. 체크포인트에서 저장하고 새 원정에서 초기화한다. 기존 완료 슬롯에서도 처치 수와 성장 기록을 읽으며 기록되지 않은 시간은 `--`로 표시한다.

### 화면과 플레이

- Haven의 여관·대장간·상점은 타일과 같은 2:1 투영식 `(2(a-b), a+b-z)`으로 다시 그렸다. 같은 폭의 처마와 일정한 왼쪽 위 조명을 쓰고, 굴뚝 바닥은 지붕 경사에 맞췄다. 크기와 지붕 색으로 세 건물을 구별한다. 벽·문·창·천막·울타리·통의 기준을 격자와 대조했다. 계산한 기하를 작은 팔레트 PNG로 구워 게임 실행 중에는 원근 계산이 없다.
- 가죽 판과 황동 리벳을 공통 UI 재질로 썼다. 방패 초상 아래에는 손실된 체력을 붉은 밀랍색으로 드러낸다. 지역 제목은 두루마리로 펼치고, 진행 알림은 위에서 천 깃발로 내렸다 올린다. Pulse는 황동 메달 외곽에서 충전을 보여 주고 완료할 때 짧게 반짝인다. 원정 결과와 현장 노트는 펼친 장부로 표시한다. 최대 전투 HUD 면적은 다섯 단원 기준 **14.89%**다.

- 진흙에는 곱하기, 강철·황동·비취·영혼에는 가산, 망령 연기와 브루트 돌에는 알파 블렌드를 쓴다. 빛기둥이 사라질 때 하위 방출기가 불씨를 낸다. Stag의 붉은 룬은 타격 반경을 표시하고 착지하면 균열과 돌 파편이 남는다. 처치 시 영혼이 올라가고 크라운은 포물선으로 튀었다가 대장에게 돌아온다. 작은 텍스처 시트와 수명 곡선·색/알파 보간을 사용한다. 체력과 피해 숫자는 타격 효과 위 레이어에서 그린다.
