# SeedLab 턴 이동과 리플레이

SeedLab(`Scenes/ShowcaseMaze.scene`)에서 **WASD** 또는 **방향키**를 한 번 누르면 탐험가가 이웃 타일의 중심으로 한 칸 이동한다. 벽을 향한 이동과 **Space**로 대기하기는 현재 칸에서 한 턴을 쓴다. 키를 길게 누르면 한 번만 진행하고, 아무 입력이 없으면 턴 수도 그대로다. 오른쪽 상태 줄에 현재 턴이 표시된다.

| 조작 | 동작 |
| --- | --- |
| **K** | 현재 시드로 입구부터 진행한 턴을 저장한다. 마지막으로 저장한 리플레이 한 개를 유지한다. |
| **T** | 저장한 시드로 던전을 복원하고 입구부터 자동 재생한다. 한 턴은 0.05초(직접 걸을 때의 두 배 빠르기)다. |
| **J** | 저장한 기록을 입구에서 멈춘 채로 연다. 다시 누를 때마다 한 턴을 진행한다. 자동 재생 중에 누르면 그 턴에서 멈춘다. |
| **R** | 현재 시드의 입구로 돌아가 새 기록을 시작한다. **N / P**로 시드를 바꾸거나 SEED 입력란과 **Go**로 직접 지정해도 새 기록이 시작된다. |

직접 비교하려면 SEED 입력란에 **42**를 입력하고 **Go**를 누른다. 입구에서 방향키 몇 번과 **Space**(기다리기)를 섞어 누르고 **K**로 저장한다. **N**으로 다른 던전을 연 뒤 **J**를 누르면 시드가 42로 돌아간다. **J**를 누를 때마다 탐험가가 기록대로 한 턴씩 움직이고(벽에 막힌 턴과 기다린 턴은 제자리), 마지막에 모든 턴이 일치했다는 메시지가 뜬다.

기록 파일은 기존 게임별 사용자 데이터 폴더의 `latest.replay`다. 편집기 Play는 `Play/<프로젝트 ID>`를, 배포 게임은 `Games/<프로젝트 ID>`를 사용한다. 기본 속도나 키 배치를 바꿔도 녹화된 명령의 순서는 같다. 서로 다른 실행 환경에서도 같은 파일을 읽을 수 있다. [실행별 캡처와 검증 기록](../../engine/tests/results/turn-replay/README.md)

## 게임 스크립트에서 사용하기

`GridTurnRun.Record`에 게임 규칙 ID, 생성기 버전, 시드, 맵 크기 설정과 시작 좌표를 전달한다. SeedLab은 크기를 방의 열·행 수로 저장한다. 새 입력이 들어올 때마다 `PlayTurn(command, tryEnter)`를 한 번 호출한다. `tryEnter`는 목표 칸으로 이동에 성공하면 true, 벽에 막히면 false를 반환한다. 대기 명령은 그 자리에서 처리한다.

`PlayerStorage.SaveReplay(run.Snapshot())`은 시드와 각 턴의 명령·도착 좌표를 YAML로 저장한다. 로드할 때 게임이 규칙 ID와 생성기 버전을 확인하고 시작 상태를 복원한다. `GridTurnRun.Replay`로 연 후, 매 턴 `ReplayTurn`에 플레이 때와 같은 이동 함수를 전달한다. 실제 결과가 기록과 다르면 상태가 `Diverged`가 된다. 이때 `Turn`, `Position`, `LastExpected`로 최초 불일치 턴과 두 좌표를 확인할 수 있다.

한 파일에 최대 32,768턴을 담을 수 있다. SeedLab에서는 이동 키 여러 개가 같은 고정 틱에 들어오면 위·오른쪽·아래·왼쪽·대기 순서로 하나를 선택한다. 탐험가 이동은 엔진의 `TryMoveStep`이 전체 변위의 충돌을 먼저 검사해 처리한다. [엔진 턴 API](../../engine/src/Engine.Core/GridTurns.cs) · [SeedLab 구현](../../samples/SeedLab/Scripts/MazeRun.cs)
