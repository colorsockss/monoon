# 2. IsoBand — 아이소메트릭 용병단 액션 RPG (가칭)

[샘플 계획 목차](README.md)

## 게임 개요

- 장르 참고: 여러 영웅이 한 무리로 움직이며 자동으로 싸우는 캐주얼 핵 앤 슬래시 RPG. 이름·영웅·설정·그림은 모두 새로 만든다([독창성 규칙](README.md#장르-참고와-독창성)).
- 조작: 한 손으로 한다. 방향키·WASD·왼쪽 스틱 또는 마우스 클릭 지점으로 대장이 이동하고, 동료는 대장을 따라 대열을 유지한다. 공격은 사거리 안의 적에게 자동으로 한다. 직접 누르는 것은 스킬 버튼 하나(용병단 전체 필살기, 쿨다운)뿐이다.
- 흐름: 마을(주점·대장간·출발 문) → 필드 2곳 → 던전 1곳(웨이브 몰이, 마지막에 보스). 필드에서는 캠프를 세워 잠깐 쉬면 체력과 자원이 찬다.
- 성장: 주점에서 영웅을 고용한다(직업 4종: 방패병·검사·궁수·치유사, 최대 6명). 레벨이 오르면 고용 슬롯이 늘어난다. 장비는 무기·방어구 2칸, 등급 3단계.
- 분량: 처음부터 보스까지 20–30분.

## 맵과 타일

| 레이어 | 내용 | 쓰는 엔진 기능 |
| --- | --- | --- |
| 바닥 | 풀·흙길·돌바닥·물 | Tilemap 2D(Isometric 64×32), 6방향(등각은 4방향 연결) 오토타일, 무작위 타일 |
| 막힘 | 물·절벽 칸 | 타일 충돌(Full cell), 자유 이동 길찾기 굽기(S4 확인) |
| 키 큰 물체 | 나무·벽·기둥·집 | Y sort 스프라이트 프리팹(S3, 타일 아님) |
| 표시 | 클릭 지점, 스킬 범위 | 선 그리기, 반투명 스프라이트 |

- 필드는 시드로 지형을 만들고 씬에 구운 뒤 손으로 다듬는다. 던전은 방 몇 개를 이어 붙인다.
- 캐릭터·적은 발 기준 Y 정렬(Sorting Group 2D)로 나무·벽과 앞뒤가 맞아야 한다.

## 사용하는 엔진 기능

- 이동: 자유 이동 길찾기(`BakeArea`, `NavCrowd2D`)로 동료와 적이 서로 비키며 움직인다. 마우스 클릭 지점은 S1(`TileCellAt`)로 칸을 찾는다.
- 대량 오브젝트: 적 100–300마리와 화살·마법탄은 프리팹 풀(BarrageLab의 스프라이트 풀)로 만든다. 공간 질의(격자 인덱스)로 사거리 안 적을 찾는다.
- 애니메이션: 8방향 클립 세트(애니메이터 Vector2 방향), 공격 프레임 이벤트로 피해 적용.
- 효과: 타격 파티클, 데미지 숫자(Text 2D), 보스 등장 카메라 흔들림, 던전 조명.
- UI: 용병단 목록, 주점 고용 창(그리드), 장비 교체(끌어 놓기 칸), 미니맵.
- 오디오: 마을·필드·던전 음악, 버스·덕킹(보스 경고음).
- 저장: 슬롯 저장(용병단·장비·진행), 데이터 에셋으로 영웅·적·장비 정의 표.
- 트윈: 아이템 획득 팝, UI 열림.

## 엔진 보강

| ID | 이 샘플에서 쓰는 곳 |
| --- | --- |
| S1 | 마우스 클릭 이동, 스킬 범위 칸 표시 |
| S3 | 나무·벽과 캐릭터 앞뒤. 먼저 스프라이트 프리팹으로 하고 수백 개에서 프레임 비용을 잰다 |
| S4 | 등각 맵에서 자유 이동 길찾기 굽기가 셀 모양과 맞는지 확인 |

## 단계

| 단계 | 내용 | 완료 기준 |
| --- | --- | --- |
| 1 | 등각 필드 하나, 대장 이동(키·마우스), 동료 2명 따라오기, 적 1종 자동 공격 | Scene Play에서 적을 잡고 경험치가 오른다 |
| 2 | 직업 4종, 고용·레벨·장비, 필드 2곳·던전 웨이브·보스, 캠프 | 마을에서 보스까지 끝낼 수 있다 |
| 3 | 8방향 애니메이션, 효과·사운드, UI 다듬기, 저장 슬롯 | 처음 켜서 저장·이어하기까지 흐름이 이어진다 |
| 4 | 입력 녹화 하네스, 성능 측정, Release·AOT 비교, 매뉴얼 | 세 경로 trace 일치, 적 300마리에서 프레임 예산 안 |

## 검증

- 하네스 `IsoBand.Play`: 고정 시드의 던전 웨이브를 입력 녹화로 재생해 용병단 체력·적 수·처치 순서 trace와 캡처를 비교한다. 자동 전투는 결정적이어야 한다(`Affine2D` 규칙, 고정 틱, 시드 난수).
- 성능: 적 300마리 + 동료 6명 + 탄 200개 장면의 Step·Draw 중앙값과 틱당 할당(목표 0 B), Native AOT 크기를 기록한다.
