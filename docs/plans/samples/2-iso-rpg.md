# 2. IsoBand — 랜턴 용병단

[플레이 매뉴얼](../../manual/isoband.md) · [검증 기록](../../../engine/tests/results/isoband/README.md)

Haven의 작은 광장에서 출발해 물가의 랜턴을 따라 세 지역의 봉인을 푸는 아이소메트릭 RPG다. 파티는 대장과 방패병·궁수로 시작한다. 고용과 장비 강화는 Haven에서, 회복은 전투가 끝난 모닥불에서 한다.

| 지역 | 구성 |
| --- | --- |
| Haven | 여관·대장간·상점과 광장, 모닥불의 Ysra, 원정 관문 |
| Ashwater Marsh | 청록 습지와 갈대·안개, 3무리 9마리 |
| Fallen Gallery | 석양빛 석단과 아치, 3무리 12마리 |
| Stag Crypt | 보라색 무덤과 횃불, 두 무리와 Stag Guardian |

## 제작 기준

- 64×32 등각 지형을 손으로 배치한다. 12개 타일 변형에 길과 얕은 물을 구분하고, 노출된 두 변에 둑 면을 붙인다. 바깥 물은 배경을 드러낸다. 이동 비용 0으로 표시한 물은 등각 마름모와 에이전트 반경을 기준으로 엔진 탐색 영역에 반영한다.
- Haven의 여관·대장간·상점과 천막은 같은 2:1 투영식에서 그린다. 처마 길이와 조명 방향을 고정하고 건물 폭·높이와 지붕 색을 바꾼다.
- 캐릭터 실루엣을 유지한 4프레임 대기·이동과 공격·피격·낙하 클립을 사용한다. 엔진 Animator가 자세 파라미터를 읽고, 이동·조준 방향에 따라 모션 스프라이트의 좌우를 반전한다. 아군과 적이 각각 팔레트 아틀라스 한 장을 공유한다.
- 전투의 각 역할이 공격 사거리·애니메이션·효과에서 드러나도록 한다. 대장의 4프레임 검 궤적, 방패 충격파, 화살 꼬리와 치명타, 치유 나선을 역할별로 구분한다. Stag Guardian의 붉은 룬은 타격 전에 나타나고 착지하면 균열로 바뀐다. 엔진 파티클은 재질별 작은 시트, 수명 곡선, 색상·알파 보간, 방출기별 상한을 사용한다. 저장과 전투는 고정 틱에서 처리하고, 화살·크라운·데미지 숫자 슬롯은 재사용한다.
- 초상과 체력, 랭크와 경험치, Pulse는 화면 가장자리의 가죽 9-slice 패널에 배치한다. 체력 바 배경은 밀랍색, Pulse 진행은 황동 메달의 테두리에 표시한다. 현장 노트는 Tab으로 연다. 지역 두루마리는 위 중앙에서 좌우로 펼쳐지고 진행 알림은 천 깃발로 내려온다. 엔딩과 현장 노트는 가죽 장부에 들어간다. 레벨업 메시지는 월드 텍스트로 그린다. 카메라 그룹은 대장과 현재 전투 중인 적의 중심을 담는다.

## 아트 재생성

저장소 루트에서 아래 명령을 실행한다. Pillow는 제작 스크립트가 사용한다. 게임은 구운 PNG와 합성 WAV를 사용한다. 배포할 때 씬·모션·효과는 엔진 콘텐츠 번들로 압축된다. `.monoon-assets`는 MoNoon 프로젝트를 열거나 빌드할 때 갱신된다.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 samples/IsoBand/Tools/art.py
PYTHONDONTWRITEBYTECODE=1 python3 samples/IsoBand/Tools/scenes.py
./monoon test project samples/IsoBand
```
