# 1. LedgeRun — 일반 타일맵 플랫포머

[샘플 계획 목차](README.md) · [플레이 매뉴얼](../../manual/ledgerun.md) · [제작 및 검증 기록](../../../engine/tests/results/ledgerun/README.md)

## 게임 개요

- 횡스크롤 플랫포머. 스테이지 3개(초원 → 동굴 → 탑)와 짧은 보스 방 하나. 한 스테이지는 1–3분 분량이다.
- 조작: 이동, 점프(길게 누르면 높이), 벽 미끄러지기와 벽 점프, 대시 1회(공중 포함). 키보드와 게임패드.
- 목표: 스테이지 끝 깃발. 길에 코인과 숨은 보석(스테이지당 3개)이 있다. 체력 3칸, 체크포인트에서 다시 시작한다.
- 적 3종: 좌우 순찰, 점프하며 쫓아옴, 고정 포탑(탄을 쏨). 보스는 패턴 3개를 번갈아 쓴다.

## 맵과 타일

| 레이어 | 내용 | 쓰는 엔진 기능 |
| --- | --- | --- |
| 배경 | 하늘·산·나무 2–3겹 | Parallax 2D, Sprite Renderer Tiled |
| 지형 | 바닥·벽·경사(45°·22.5°)·단방향 발판 | Tilemap 2D(Orthogonal 16×16), 8방향 오토타일, 타일별 충돌 도형·단방향 발판 |
| 장식 | 풀·횃불·물 | 무작위 타일, 움직이는 타일 |
| 위험 | 가시·용암 | 타일 Terrain(`hazard`)을 스크립트가 읽음 |

- 탑 스테이지는 세로로 길어 **청크 스트리밍**(반경 1)을 켠다. 동굴은 **2D 조명**(Global Light 2D + 횃불 그림자)을 쓴다.
- 움직이는 발판과 회전 톱은 경로(Path)·조인트로 만든다.

## 사용하는 엔진 기능

- 물리: 캐릭터 이동(경사·점프·이동 발판), 캡슐 충돌체, 트리거(코인, 체크포인트, 가시).
- 카메라: 데드존·앞보기, 맵 경계, 보스 방에서 그룹 프레이밍, 피격 흔들림. 정수 배율 표시.
- 애니메이션: 애니메이터(대기·달리기·점프·낙하·벽·대시·피격), 프레임 이벤트로 발소리.
- 효과: 착지 먼지·대시 잔상 파티클(`.particles`), 화면 효과(피격 번쩍임).
- 입력: 입력 버퍼(점프 선입력), Hold 판정(높은 점프), 패드 진동.
- UI: HUD(체력·코인·보석), 일시정지 메뉴, 스테이지 선택 화면, 결과 화면. 서식 텍스트로 수치 강조.
- 오디오: 음악(Ogg)·효과음 버스, 일시정지 스냅샷, 대사 없음.
- 저장: 슬롯 3개, 스테이지 기록(클리어·보석·최단 시간), 설정(조작키·볼륨).
- 씬: 스테이지마다 씬 하나 + 공통 UI 씬을 추가 로드.

엔진 보강은 필요 없을 것으로 본다(README의 S6). 만들면서 막히는 것은 보강 후보로 올린다.

## 단계

| 단계 | 내용 | 완료 기준 |
| --- | --- | --- |
| 1 | 초원 스테이지 하나: 이동·점프·코인·깃발, 지형 레이어, 카메라 | Scene Play에서 끝까지 갈 수 있다 |
| 2 | 벽 점프·대시, 적 3종, 체력·체크포인트, 동굴·탑 스테이지, 보스 | 세 스테이지와 보스를 클리어할 수 있다 |
| 3 | 애니메이션·파티클·조명·사운드, 메뉴·결과 화면, 저장 슬롯 | 처음 켜서 저장·이어하기까지 흐름이 이어진다 |
| 4 | 입력 녹화 하네스, Release·AOT 비교, 크기·프레임 기록, 매뉴얼 | 세 경로 trace 일치, Linux 게스트 재생 일치 |

## 검증

- 하네스 `LedgeRun.Play`: 스테이지별 입력 녹화 3개(체크포인트 재시작 포함)를 재생해 플레이어 위치·코인·체력 trace와 마지막 프레임 캡처를 비교한다.
- 측정: 탑 스테이지의 청크 경계 이동 시간, 동굴 조명 프레임 비용, 틱당 할당 0 B 목표.
- 기존 PlatformerLab의 실험 씬은 그대로 둔다. LedgeRun은 그 기능을 게임으로 묶은 것이다.
