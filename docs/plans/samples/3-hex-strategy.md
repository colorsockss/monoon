# 3. HexRealm — 헥사고날 턴제 전략 (가칭)

[샘플 계획 목차](README.md)

## 게임 개요

- 장르 참고: PC 게임 '문명' 시리즈. 육각 맵 위에서 도시를 세우고, 도시가 주변 칸을 일구어 자원을 얻고, 기술을 연구하고, 한 칸에 한 유닛씩 움직이는 PC 턴제 전략이다. 한 판을 짧게 끝낼 수 있게 규칙과 맵을 줄인다. 국가·지도자·유닛·기술·지형 이름과 그림은 모두 새로 만든다([독창성 규칙](README.md#장르-참고와-독창성)).
- PC 기준 조작: 마우스로 칸·유닛·도시를 고르고 우클릭으로 이동·공격 명령, 휠로 확대, 가장자리·드래그로 지도 이동. 단축키(턴 종료 Enter, 다음 유닛 Space, 도시 건설 B 등)와 툴팁. 창 크기 변경과 전체 화면을 지원한다.
- 판: 육각 맵 약 30×20칸(600칸), 플레이어 1 + 컴퓨터 1–2. 한 판 30–60턴, 15–30분.
- 승리 조건(하나만 달성): 상대 수도 점령 / 맵 칸의 40% 영토 / 60턴 후 점수 1위.
- 자원 3종: 식량(도시 성장), 생산(유닛·건물), 금(유지비·구매). 지형마다 산출이 다르다.
- 유닛 5종: 개척자(도시 건설), 일꾼(칸 개량: 농장·광산·도로), 정찰병(시야 넓음), 창병(방어), 궁병(원거리). 이동력과 지형 비용으로 움직이고, 전투 유닛은 한 칸에 하나만 설 수 있다.
- 기술: 작은 기술 트리(10–12개, 3시대). 연구가 끝나면 유닛·건물·칸 개량이 열린다.
- 도시: 세운 칸 주변 1칸이 영토가 되고 문화가 쌓이면 넓어진다. 인구 수만큼 주변 칸을 일구어 산출을 얻는다(자동 배치 + 직접 지정). 건물 4종(곡물 창고·작업장·성벽·도서관)과 생산 대기열.
- 전투: 근접·원거리, 지형 방어 보너스, 결과는 공식대로 정해진다(무작위 없음, 또는 시드 난수로 고정).

## 맵과 타일

| 레이어 | 내용 | 쓰는 엔진 기능 |
| --- | --- | --- |
| 지형 | 초원·숲·언덕·산·물·사막 | Tilemap 2D(Hex · Pointy 48×56), 타일 Terrain·Cost, 6방향 오토타일(해안선) |
| 자원·도시 | 자원 표시, 도시 그림 | 별도 타일 레이어 또는 스프라이트 |
| 영토 | 플레이어 색 테두리 | 선 그리기(경계 변만), 또는 반투명 오버레이 타일 레이어 |
| 표시 | 이동 범위·경로·공격 대상 | 오버레이 타일 레이어(`SetTile`), 경로 선 |
| 안개 | 못 본 칸·지금 안 보이는 칸 | 안개 타일 레이어(S5) |

- 맵은 시드로 만든다(대륙 모양 노이즈 → 지형 → 자원 배치 → 시작 위치). 같은 시드는 같은 맵이다.

## 사용하는 엔진 기능

- 칸 선택: 마우스로 칸을 고르고(S1 `TileCellAt`), 유닛을 칸 중심에 놓는다(`TileCellCenter`).
- 길찾기: 육각 6방향 길찾기와 이동 범위(S2). 지형 비용은 타일셋의 `moveCost`에서 읽는다.
- 턴: 명령 기록·리플레이(`GridTurnRun` 방식 재사용 또는 샘플 스크립트의 명령 목록). 저장은 시드 + 명령 목록으로 한다.
- 시야: 유닛·도시 주변 반경으로 안개 레이어를 밝힌다(S5). 육각 직선은 `TileGrid.HexLine`.
- AI: 샘플 스크립트. 개척자 확장, 위협 칸 회피, 약한 유닛 공격의 단순한 규칙 AI. 한 턴 계산 시간 상한을 둔다.
- 카메라: 끌어 이동·확대(줌 최소·최대), 유닛으로 이동.
- UI: 상단 자원·연구 막대, 도시 창(일구는 칸·건물·생산 대기열), 기술 트리 화면, 유닛 정보, 턴 종료 버튼, 미니맵, 툴팁.
- 트윈: 유닛 이동(칸 사이 보간), 전투 연출.
- 저장: 슬롯(시드 + 명령 목록 + 검증용 상태 해시).

## 검증

- 하네스 `HexRealm.Play`: 고정 시드 + 기록한 명령 목록(플레이어와 AI 모두)으로 40턴을 재생해 턴마다 상태 해시(도시·유닛·영토·자원)를 비교한다. Scene Play·Release·Native AOT·Linux x64가 같아야 한다.
- 측정: AI 한 턴 계산 시간(목표 50 ms 이하), 안개 갱신 시간, 600칸 맵의 프레임 비용과 할당, Native AOT 크기.
