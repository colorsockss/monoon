# 3. HexRealm — 솔트 해안

플레이어와 AI 한 세력이 해안의 산길을 사이에 두고 경쟁한다. 최대 25턴이며 첫 플레이 목표는 5–10분이다. 수도를 잃으면 즉시 패배한다. 플레이어는 적 수도 점령, 통행 가능한 영토 40% 확보, 또는 마지막 턴의 점수 우세로 승리한다.

## 판의 흐름

| 구간 | 선택 |
| --- | --- |
| 솔트 해안 | 정착 위치를 고르고 정찰병을 보낸다. 생산 또는 연구에 투자한다 |
| 돌길 | 숲 엄폐와 산맥을 지나 선점할 길을 고른다. 추가 도시를 세우거나 창병과 궁병을 모은다. Redwatch와 Greyharbor는 노동자를 배치하고 전선으로 부대를 보낸다 |
| 마지막 감시 | 국경을 지키며 점수를 모을지, 병력을 모아 Redwatch를 공격할지 결정한다 |

16×12 축 좌표를 사용한다. 해안과 두 수도 주변을 먼저 잡고 시드로 산맥·숲·건조지 내부를 변주한다. 초반에는 발전 장소와 접근 가능한 통로가 보인다. 정찰에서 돌아오면 이전 시야의 경계를 양피지와 바랜 지형으로 구분할 수 있다.

## 구현

| 기능 | 방법 |
| --- | --- |
| 이동·예측 | HexPointy `GridNavigation`, 같은 점유 비용으로 탐색·범위·경로 표시 |
| 생산·연구 | 생산 재고와 로스터 상한, 농장·광산·도로, 연구 단계별 효과 |
| 영토 | 도시 성장마다 점선으로 표시한 인접 빈 칸 하나를 편입. 개척은 주위 빈 칸을 얻고 점령은 도시별 토지를 넘김 |
| 아트 | 팔레트 PNG 아틀라스, 해안·경계의 6변 마스크, 진영별 말과 도시 3단계 |
| 인터페이스 | 지도 제작자의 양피지 9-slice, GowunDodum 세피아 글자, 성장 예보를 담은 진영 리본, 턴 도장과 결과 칙서 |
| 연출 | 애니메이터 Idle/Walk/Strike, 보간 이동, 타격음과 연기, 국경의 잉크 번짐과 증가량, 칙서 펼침 |
| 저장 | 시드와 명령을 순서대로 다시 적용해 해시 확인, 완료 캠페인도 같은 방식으로 복원 |

타이틀, 보드, 결과는 같은 씬의 화면 상태다. 보드 에셋을 다시 로드하는 비용 없이 페이드를 적용한다. `RealmRules`는 정수 규칙과 명령 기록을, `RealmPresentation`은 표시 위치와 수명 버퍼를 소유한다. 타격과 연기는 같은 스프라이트 애니메이터로 재생한다. 순서와 재생 프레임이 같아 입력 리플레이에서 캡처를 비교할 수 있다.
